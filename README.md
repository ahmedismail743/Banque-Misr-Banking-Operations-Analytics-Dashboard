# 🏦 Banque Misr Banking & Operations Analytics Dashboard

An interactive, multi-page **Power BI** analytics solution built to monitor transaction activity, customer and account behavior, branch and channel performance, and loan portfolio health across **Banque Misr** operations in Egypt.

## ✨ Key Highlights & Views

* **Overview**
  * Tracks **EGP 74,360,034** in total transaction volume across **4,000 transactions** (avg. **EGP 18,590**) from **973 active customers** and **20 branches** across **6 cities** (Mansoura, Cairo, Giza, Assiut, Alexandria, and Tanta).
  * Visualizes monthly transaction trends, volume share by customer segment (**VIP**, **Mass**, **Retail**), transaction breakdown by type (**Withdrawal**, **Deposit**, **Payment**, **Transfer**), and regional distribution.
* **Customers & Accounts**
  * Breaks down balances by account type (**Fixed**: 105.5M, **Current**: 97.8M, **Savings**: 96.2M), top customer job titles (led by Retired, Engineer, Doctor, Consultant, and Accountant), monthly account opening trends, and customer segmentation (**Retail** 60%, **Mass** 30%, **VIP** 10%).
* **Branches & Channels Performance**
  * Ranks branches (e.g., **Branch_9** leading with EGP 6,342,316 across 250 transactions) with metric switching (**Total Amount**, **Total Transactions**, **Avg Transaction Amount**), city/opening date/staffing metadata, deposit-to-withdrawal ratios, and mini trend sparklines.
* **Loans Portfolio Overview**
  * Monitors **EGP 237,403,554** in total loans across **600 loans**, **EGP 3.96M** in installments, a **14.44%** average interest rate, loan origination trends (2018–2024), a **66.1%** active portfolio health gauge, a **Loan Type x Status** matrix (**Personal**, **Car**, **Mortgage** across **Active**, **Closed**, and **Defaulted**), and loan counts by segment.
* **UI/UX & Interactivity**
  * Designed with a clean card-based layout, subtle elevation shadows, Banque Misr brand colors, interactive cross-filtering, dynamic filter controls, and a **Light / Dark Mode toggle** for comfortable viewing across different lighting environments.

## 🛠️ Tools & Technologies Used

* **Microsoft Power BI** — Data modeling, star schema design, interactive report layout, cross-filtering, and custom visual presentation
* **DAX (Data Analysis Expressions)** — Dynamic KPIs, aggregations, percentages/shares, and custom HTML/CSS/JS-driven visual elements (including Light/Dark theme switching)
* **Power Query** — Data extraction, cleaning, transformation, and shaping
* **SQL (MySQL)** — Data querying, validation, and relational preparation
